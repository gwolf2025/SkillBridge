# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SkillBridge, please report it
privately by opening a security advisory on GitHub or contacting the
maintainers directly.

Do not disclose security vulnerabilities publicly until they have been
addressed.

## Security Principles

- Permissions must never be silently weakened during conversion.
- Security restrictions must be preserved or explicitly documented as changed.
- Secrets must never be logged or committed.
- No mandatory paid API is required for core functionality.
- All environment variables are optional unless explicitly documented otherwise.
