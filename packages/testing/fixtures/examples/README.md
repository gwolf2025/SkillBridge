# Example Skills — Demonstration Only

This directory contains example SkillBridge skills that exercise the package format
(SKILL.md) and conversion pipeline. They are intended for **demonstration and testing
purposes only** and are **not** production-ready skills.

Each skill is labeled with `DEMONSTRATION ONLY — Not intended for production use.`
in its description field.

| Directory         | Purpose                                                  |
| ----------------- | -------------------------------------------------------- |
| `hello-world/`    | Simple minimal skill with basic capabilities             |
| `file-organizer/` | Intermediate skill with filesystem capabilities          |
| `secret-rotator/` | Permission-sensitive skill requiring secrets access      |
| `code-analyzer/`  | Resource-bearing skill with scripts and skillbridge.yaml |
| `vendor-hooks/`   | Intentionally incompatible skill with vendor extensions  |

All skills are licensed under Apache-2.0.
