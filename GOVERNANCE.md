# Governance

SkillBridge is a community-driven open-source project.

## Current Status

**Pre-alpha / bootstrap phase.** The project is maintained by its initial contributors. Governance structures will evolve as the community grows.

## Decision-Making

- **Day-to-day decisions** are made by maintainers through pull request review
- **Architecture changes** should be discussed via GitHub Issues before implementation
- **Significant design decisions** are recorded in [DECISIONS.md](./DECISIONS.md)
- **Disagreements** are resolved through consensus-seeking; if consensus cannot be reached, maintainers have final authority

## Maintainers

Maintainers are contributors who have demonstrated sustained, high-quality contributions. Maintainer status is granted by existing maintainers.

## Contributor Path

1. Submit pull requests and participate in code review
2. Consistently demonstrate understanding of the architecture and conventions
3. Help review others' contributions
4. Take ownership of specific areas or packages
5. Be nominated as a maintainer

## Communication

- GitHub Issues for bug reports and feature requests
- GitHub Discussions for questions and general conversation
- Pull requests for code changes

## Code of Conduct

All participants are expected to follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
