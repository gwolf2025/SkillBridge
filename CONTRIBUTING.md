# Contributing to SkillBridge

Thank you for your interest in SkillBridge.

## How to Contribute

1. Read the mission and architecture documents.
2. Open an issue or discussion to propose changes before starting work.
3. Fork the repository and create a feature branch.
4. Follow the code style and testing conventions described in AGENTS.md.
5. Ensure all checks pass before submitting a pull request.
6. Add or update tests for any behavior changes.
7. Update TASKS.md and DECISIONS.md when appropriate.

## Code of Conduct

Be respectful, constructive, and professional. Harassment and
discrimination will not be tolerated.
