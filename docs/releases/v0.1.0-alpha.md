# SkillBridge v0.1.0-alpha

**Release date:** 2026-07-30

## Motivation

AI coding agents are proliferating — Claude Code, OpenAI Codex, Cursor, Windsurf, Copilot, and dozens more. Each has its own skill format. Building skills for multiple ecosystems means either maintaining N separate copies or writing N×M pairwise converters.

SkillBridge solves this with a **vendor-neutral Intermediate Representation (IR)**. Write your skill once in standard SKILL.md format, then convert it to any supported agent format through the shared IR.

## Major Capabilities

- **SKILL.md parsing** — YAML frontmatter extraction, body section splitting, diagnostic output
- **SkillBridge IR** — `NormalizedSkill`, `ResolvedIR`, `CompiledIR` with validation functions
- **Capability vocabulary** — 22 capability types across 8 categories
- **Compatibility analysis** — 6-level comparison (native, emulated, missing, degraded, partial, unknown)
- **Security-impact assessment** — Permission weakening detection and reporting
- **Policy enforcement** — Strict, safe, and permissive modes with configurable behavior
- **Deterministic compilation** — SHA-256 checksums, stable JSON serialization, atomic output writer
- **Cross-adapter conversion** — Any source → any target through IR (not pairwise)
- **Install, uninstall, verify, repair** — Full skill lifecycle management
- **CLI with 13 subcommands** — `convert`, `compile`, `parse`, `validate`, `inspect`, `adapters`, `capabilities`, `doctor`, `install`, `uninstall`, `list`, `verify`, `repair`
- **JSON output** — All commands support `--json` for machine consumption
- **Secret redaction** — Environment variable values redacted in diagnostic output

## Installation

```bash
git clone https://github.com/skillbridge/skillbridge.git
cd skillbridge
pnpm install
pnpm verify
```

Requirements: Node.js 20+, pnpm 11.17.0.

## Quick Start

```bash
# Parse an example skill
node apps/cli/dist/index.js parse packages/testing/fixtures/examples/hello-world/SKILL.md

# Convert between formats (permissive mode to allow capability gaps)
node apps/cli/dist/index.js convert packages/testing/fixtures/examples/hello-world/SKILL.md \
  --policy permissive --dry-run

# List adapters
node apps/cli/dist/index.js adapters --detail
```

## Known Limitations

- **invoke() is a placeholder** — Runtime skill execution requires an external agent environment
- **markdown-only source format** — Only `markdown` source/target format is implemented
- **No Windows CI** — CI runs on Ubuntu only (Windows is supported locally)
- **YAML body parsing** — Body sections parsed as YAML produce warnings for non-YAML content
- **Default capabilities** — Claude and Codex adapters default to permissive capabilities when no tools declared
- **ExFAT filesystem** — `pnpm install` may fail on Windows exFAT drives (use NTFS)
- See [full known limitations](../known-limitations.md)

## Who Should Use This Alpha

- Developers evaluating the IR-based conversion approach
- Contributors who want to add adapters for new agent ecosystems
- Teams standardizing on SKILL.md and exploring format conversion

## Who Should Wait

- Production deployments needing guaranteed lossless conversion
- Users needing runtime skill execution (invoke)
- Users needing JSON or YAML source format support
- Windows users on exFAT drives
